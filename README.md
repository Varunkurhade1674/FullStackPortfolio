# Varun Kurhade — Portfolio

## Setup
npm install
npm run dev

## Deploy to Vercel
Push to GitHub, then import the repo in Vercel (framework preset: Vite). No env vars needed.

## Before publishing
Open src/data/portfolioData.js and fill in:
- profile.linkedin, profile.github, profile.resumeUrl
- github / demo URLs for each project (only add real links)
